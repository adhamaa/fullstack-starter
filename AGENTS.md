# Agent instructions

Guidance for AI agents working in this repository.

## Agent skills

### Issue tracker

GitHub Issues on `adhamaa/fullstack-starter` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical triage roles map to GitHub labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: start from `CONTEXT-MAP.md`, then read each relevant `CONTEXT.md`; system ADRs live in `docs/adr/`. See `docs/agents/domain.md`.
